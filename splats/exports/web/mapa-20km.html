About this map

All OpenStreetMap data was pulled fresh on 2026-07-05 via the Overpass API for a 40 × 40 km box centred on the LQV polygon (-57.0355, -25.6073).

30,086 features across 8 categories. Rural Paraguay is sparsely mapped — these counts are a lower bound.

The DEM-derived quebrada streams (blue lines inside the polygon) come from Copernicus GLO-30 elevation, not OSM.

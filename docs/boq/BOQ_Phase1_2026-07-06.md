## How to use the BOQ (for Wes + vendors)

### For Wes

1. **Print the CSV** (or open in Google Sheets/Excel) — 103 line items, one per row.
2. **Walk through it with the cob builder** during the R07 quote call — verify the cob material quantities (m³), labor days, lime plaster kg, etc. The builder's quote should be within ±15% of the BOQ for it to be a competitive offer.
3. **Send the BOQ to Gastro-Haus + Brasitermo + Sapucai quarry** for the 3 critical vendor quotes. The 30-cabin equivalent bulk-buy pricing means **the Phase 1 vendors are the same as the Phase 2-3 vendors**, so getting good Phase 1 prices locks in the project-level supply chain.

### For builders

The CSV is the formal quote template. Each row has:
- **Qty** (the volume needed for Phase 1)
- **Unit** (m³, kg, units, m, m², etc.)
- **Unit cost (EUR)** (the budgeted estimate)
- **Vendor (PRIMARY)** (who Erebus recommends as the first call)
- **Source** (the research file that justifies the unit cost)

A builder/vendor submits a quote by either:
- **Accepting** the unit cost as-is (preferred for standard items like cement, fasteners, paint)
- **Replacing** the unit cost with their actual quote (preferred for specialty items like cob labor, septic install)
- **Adding** a new line for items not in the BOQ (rare; flag in the "Notes" column)

### For the project accountant

- **All amounts are EUR**. For PY-actual costs, divide by 8,025 to get PYG (or use the Sources sheet in the financial model xlsx for FX conversion).
- **10% contingency** is standard for PY construction — Wes can pull from this for any line overage.
- **No inflation applied** — these are 2026-07-06 prices. The financial model projects 5%/yr PYG inflation through the Phase 2-3 buildout.

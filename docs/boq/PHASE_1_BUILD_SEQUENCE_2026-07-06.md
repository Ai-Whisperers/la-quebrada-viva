## Critical path + parallelization

The **critical path** (longest dependency chain):

1. Site infrastructure → foundations → cob walls → interior finishes → opening (Weeks 1-36)
2. Cabins: cob walls + lime plaster + roofs → interiors (Weeks 9-28)
3. Restaurant: shell (parallel with cabins) → kitchen equipment → opening (Weeks 9-36)
4. Pool: depends on cabins + restaurant being done (Weeks 29-30)

**Parallelization**:
- **Weeks 1-4** (site infra): cannot be parallelized with anything (must be first)
- **Weeks 5-8** (foundations): can run in parallel with Weeks 9-24 if crew is sized right
- **Weeks 9-24** (cob walls + roofs): can run 2-3 cabins in parallel with the others being roofed/interiored
- **Weeks 25-30** (interiors + restaurant + pool): can mostly run in parallel

**Total crew peak**: ~12-15 workers in Weeks 9-24. Smaller in Weeks 1-8 (3-6 workers) + Weeks 25-30 (8-12 workers).

## Seasonality (CRITICAL)

**Build only in dry season (May-Oct)** for cob/earthen work. This is a hard constraint from M_COB_01.

- **Recommended Phase 1 start**: April 2027 (early dry season, before main rainy months are over)
- **Recommended Phase 1 finish**: December 2027 (early rainy season, but Phase 1 is operational by then)

Alternative: **Start September 2026** (right now, just past dry season start) for the site infrastructure + foundations + cabin cob walls before the November-March rainy season. Then **interiors + restaurant + pool** during the rainy season (these are mostly weather-protected work).

## Risk mitigation

| Risk | Mitigation |
|---|---|
| Wet season delays cob-drying | Cover walls with tarps during construction; accept 1-month buffer |
| PY peso devaluation | USD-priced forward contract on $50K of materials (cement, rebar, solar) |
| Vendor late delivery | Buy 30-cabin equivalent upfront for Phase 1 (per SUPPLY_CHAIN §B) |
| Crew injury | IPS + insurance first-year premium (per CAPEX_OPTIONS §E.8) |
| Find during excavation (cultural artifact) | FIND_PROTOCOL signed by all builders before work starts |
| Storm damage to incomplete walls | Tarps + emergency cover budget (5% of build cost) |

## The 3 hard dependencies (don't start without these)

1. **Mbyá consultation complete** (W+4 in the 30-day plan). The first cabin construction shouldn't start before the Mbyá have blessed the land.
2. **Archaeological survey done** (per ARCHAEOLOGICAL_CULTURAL_RESEARCH §6). Site walk + 1-2 day ground survey + "no finds" letter.
3. **HG-3 insurance in hand**. Construction without insurance is a non-starter for a 62-ha forest property.

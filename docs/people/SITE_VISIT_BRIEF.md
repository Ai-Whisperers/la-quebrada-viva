# W1.2 — Site visit prep brief (Wes's next PY trip)

**Purpose:** Make Wes's next PY visit maximally productive. The visit answers 7+ research items (F03, F05, F06, F07, PA10, W17, SD10) + 1 critical insurance question + 1 commercial question.

**Duration:** 5-7 days in PY recommended (not just a day trip)

---

## Day-by-day plan

### Day 1 — Arrival + Asunción ground floor

**Morning:**
- [ ] ANDE office Paraguarí — apply for 3-phase capacity assessment (F03)
  - Bring: property documents, RUC if available
  - Request: formal capacity letter + 3-phase upgrade quote
  - **Estimated time:** 2 hours (incl. travel to Paraguarí from Asunción)
  - **Cost:** free application, 4-8 month wait for technical response

- [ ] Buy 3 SIM cards (Tigo, Personal, Claro) for cell coverage test (F11)
  - Tigo + Personal + Claro SIMs
  - Each costs ~$5-10 USD
  - **Total cost:** $15-30

**Afternoon:**
- [ ] ANDE field check at property: pole + transformer (F07)
  - Walk property, photograph any existing electrical infrastructure
  - Note distance from nearest 3-phase line
- [ ] Cell coverage test (F11)
  - Use NetMonster (Android) or Field Test Mode (iPhone)
  - Test at: property entrance, proposed cabin cluster 1, restaurant site, reception site, driveway entrance
  - Photograph signal strength readings

### Day 2-3 — Property survey (the big days)

**Goal:** walk the entire 62 ha, photograph everything, mark GPS coordinates, identify issues

- [ ] Topographic survey (F05 + SD10):
  - Walk all 6 fincas (per the property's KML)
  - Photograph terraces, stream, existing structures, road, pool location, escarpment
  - Use phone GPS to mark key points
  - Drive the full access road (note Oct-Apr rain issues)
  - Note any soil erosion, drainage issues
- [ ] Water source assessment:
  - Locate existing stream
  - Note flow rate (visual estimate + season)
  - Identify potential well drilling sites
  - Mark where INAA water permit would apply (F14)
- [ ] Forest cover assessment:
  - Photograph canopy at multiple points (for the Hansen GFC cross-check)
  - Note any clearings or fire damage
  - Identify 3-5 candidate house sites (S06)

### Day 4 — Kuikopee forester meeting (PA10) + restaurants visit (M22)

- [ ] Travel to Caacupé (~1 hr from Escobar)
- [ ] Meet the Dutch forester Wes mentioned (PA10)
  - Bring: property location, goals (native reforestation, terrain beautification)
  - Topics: native plant species list, reforestation plan, Phase 1+2 timeline
  - **Outcome:** contact info + initial species list + potential Phase 1 collaboration
- [ ] Lunch in San Bernardino — visit Gastro-Haus (M22) + 1-2 restaurants
  - Get quote for Phase 1 commercial kitchen equipment
  - Ask restaurant owners about: what broke, what they wish they knew, supplier recommendations
  - **Goal:** 3 supplier quotes + 2 "what to learn from" interviews

### Day 5 — Infrastructure verification (F06, F08, W17)

- [ ] ANDE grid capacity follow-up (F06) — if office has more details
- [ ] Local well-drillers + electricians list (F08)
  - Get 3 quotes from local well-drillers
  - Get 3 quotes from local electricians
- [ ] Staff transport check (W17):
  - Bus routes: Paraguarí → Escobar
  - Frequency + cost
  - Any private transport options
  - Note commute times from common worker origin points

### Day 6 — Commercial + loadout

- [ ] Feeder markets + commercial suppliers:
  - Costeo.com.py office (if any in Asunción)
  - Local ferreterías for tools/equipment
  - 1-2 carpenters for cabin construction (M09 fasteners + M10 flooring question)
  - Hardware stores for bathroom + kitchen fixtures

### Day 7 — Return + final report

- [ ] Write up site visit findings in `docs/site_data/site_visit_2026-MM-DD.md`
- [ ] Update all 7+ research items in RESEARCH_CATALOGUE
- [ ] Hand photos to Erebus for: terrain model update, road condition, cabin site selection

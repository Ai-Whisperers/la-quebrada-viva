## Pricing detail per material

### 1. Ceramic tile (cerámica) — economical baseline
- **Source brands:** **Cerámica Asunción (Coronel Oviedo factory)**, **Keros Paraguay**, **Embajada** (Brazilian in PY)
- **Specs:** R10+, 30x30 cm + 45x45 cm standard
- **Cost per m² installed:** $12-22 (material $7-12 + labor install $5-10)
- **Lead time:** Local stock; 3-7 days from Asunción
- **Slip rating:** R10-R11 (good)
- **Best for:** Kitchen floors, bathroom floors (where moisture + spills demand sealed surface)

### 2. Porcelain tile (porcelanato) — premium durability
- **Source brands:** **Portinari (BR)** + **Cerro León (PY)** + **Eliane (BR)**
- **Specs:** R11-R13, full-body porcelain, 60x60 cm common
- **Cost per m² installed:** $22-40 (material $14-25 + labor install $8-15)
- **Lead time:** 5-10 days (out-of-stock sizes can take 2-3 weeks)
- **Slip rating:** R11-R13 (excellent)
- **Best for:** Main living areas, premium cabin floor where high durability matters

### 3. Polished cement (mortero alisado) — cob companion
- **Specs:** Hand-troweled cement + sand + selected aggregates, sealed with varnish or hard wax
- **Cost per m² installed:** $18-30 (mostly labor — $12-20/m² labor on top of $5-10/m² cement)
- **Lead time:** 2-4 weeks (form + pour + cure + polish + seal)
- **Slip rating:** R9-R10 (requires seal; not pool-area wet)
- **Best for:** Bedrooms, main living areas; cob-house-typical aesthetic
- **Climate fit:** ⚠️ Needs annual reseal in PY humidity or surface degrades in 18-24 months

### 4. Reclaimed local wood (lapas, eucalyptus repurposed) — highest aesthetic
- **Sourcing:** Demolition sites, barn wood reclamation, restored heritage wood. Mínimum 30-year-old boards.
- **Specs:** Kiln-dried to <12% moisture, treated (submerged borate + boric acid) for exterior
- **Cost per m² installed:** $25-50 (sourcing $10-20 + install labor $10-20 + treatment/seal $5-10)
- **Lead time:** 14-30 days (sourcing is the bottleneck)
- **Slip rating:** R10 (treated)
- **Best for:** Signature cabin floors (Type A "romantic 2p cob cabin")
- **Climate fit:** Best when interior-only — exterior decking needs premium seal every 6-12 months

### 5. Bamboo flooring (mature Guadua angustifolia)
- **Sourcing:** Misiones (PY), Caaguazú (PY); pre-graded strips for floor use
- **Specs:** Kiln-dried + treated + densified (5mm thick strips)
- **Cost per m² installed:** $20-35 (material $12-20 + install labor $8-15)
- **Lead time:** 14-30 days (kiln-drying is the bottleneck)
- **Slip rating:** R9 (smooth; needs further treatment for wet areas)
- **Best for:** Eco-cabin signature aesthetic; works well with cob + bottle walls
- **Climate fit:** ⚠️ Variable — if budget for premium kiln-drying + treatment, 15+ years; else 5-8 years max

### 6. Microcement — premium minimalist
- **Material:** Cement + polymer + fine aggregates applied in 3-5 thin coats
- **Specs:** 3-4 mm total thickness; covers most substrates; sealed with polyurethane
- **Cost per m² installed:** $35-55 (almost all labor — $25-35/m² labor + $8-15/m² material)
- **Lead time:** 7-14 days (multi-coat application + cure)
- **Slip rating:** R9-R11 (depending on final coat)
- **Best for:** Modern minimalist look — works well if LQV shifts to contemporary aesthetic
- **Climate fit:** Excellent when sealed + maintained

## Climate fit summary (per WES_WARNINGS.md)

- **Best:** porcelain + ceramic (sealed surfaces, max PY humidity resilience)
- **Strong:** microcement (sealed)
- **Good:** polished cement + bamboo + reclaimed wood (require annual reseal)
- **Pool-deck area:** porcelain R13 only; no polished cement (slippery when wet despite R-rating)
- **Avoid in PH-1:** untreated wood floor, untreated bamboo (fail in 18-24 months)

## Key Risks

1. **Polished cement in PY humidity** requires annual reseal; if Wes omits maintenance, surface degrades in 18-24 months.
2. **Reclaimed wood supply unreliable** — 14-30 day lead time; plan ahead with 2-3 sources.
3. **Microcement requires expert labor** — limited PY tradespeople, +30% labor cost vs standard cement.
4. **Bamboo climate variability** — kiln-dried premium cost is essential; cheap bamboo fails fast.
5. **Floor finish mismatch between cabin types** if multiple flooring tradesmen on site — single-source recommended.

## Recommendation

**For Phase 1 (5 cabins):**
1. **Lead:** porcelain **Portinari 60x60** for all luxe + spa areas (R12+ slip rating).
2. **Companion:** reclaimed lapacho for cabin Type A romantic + boomhut signature areas.
3. **Budget:** polished cement for basic + kid-area floors.
4. **Total cost: ~$10k for ~290 m² = $35/m²** (mid-tier cost vs all-premium or all-budget).

**Single source for installation:** hire 1 crew of 4 PY-tradesmen specialized in all 3 finishes; reduces coordination + ensures consistent grout color + sealant batch.

**Phase 2+:** consider bamboo flooring premium kiln-dried if 2-3 FY of data confirms maturity is sufficient.

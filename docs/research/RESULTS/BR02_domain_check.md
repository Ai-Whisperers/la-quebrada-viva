## How to check

**Option A: Manual whois (free)**
```bash
# From the VPS (works for most TLDs)
whois riverstonevalley.com
whois riverstonevalley.io
whois riverstonevalley.co
whois riverstonevalley.com.py
```

**Option B: Web lookup (faster)**
- https://www.namecheap.com/domains/
- https://name.com/
- https://www.godaddy.com/domainsearch/

**Option C: NIC.py for .com.py specifically**
- https://www.nic.py/

## Also check social media handles

For each name candidate, check availability on:
- Instagram: https://www.instagram.com/{name}
- Facebook: search for the name
- TikTok: same
- YouTube: same
- X (Twitter): https://twitter.com/{name}

**Best practice:** register handles on all 4-5 platforms even before content is posted. Avoids squatting.

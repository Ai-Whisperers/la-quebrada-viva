### CDE / Brazilian-import landscape

Ciudad del Este is the BR border wholesale hub — fasteners are typically **30-50% cheaper** than PY wholesale after factoring customs + IVA.

**CDE pricing pattern (estimated 2026):**
- Common nails 3" (1 kg): $0.40-0.65/kg
- Wood screws #8 x 2" (per 100): $1.20-1.80
- Lag bolts 3/8" x 4" (per 10): $1.50-2.50
- Hurricane ties: $0.20-0.35/each
- Joist hangers: $0.50-0.90/each

**Customs duties (CDE → Asunción, 2026 estimate):**
- IVA: 10%
- Import tariff: 8-14% depending on whether BR has PAR/MERCOSUR preference
- PAR (Paraguay-Argentina regional agreement): typically waived for Argentine goods (PY imports a lot via Argentine present)
- **Effective markup on CDE → Asunción:** ~25-35% total (customs + IVA + transport + handling)

## Logistics playbook

### If buying 60% locally + 40% CDE
1. **Week 1:** Order Asunción ferretería for the common nails + anchor bolts + post anchors (3-day delivery to Escobar).
2. **Week 2:** Wes or capataz does **day trip to CDE** for hurricane ties + joist hangers + stainless (+200 kg consolidated container = ~$1,200 all-in via Cartes shipping CDE→Asunción).
3. **Week 3:** Delivery to site.

### Alternative: One consolidated CDE trip via freight broker
- **Transporte CDE-Asunción Express** (multiple operators) — full container (700 kg) CDE → Asunción ~$180-220.
- Escoba to Asunción pickup + truck to Escobar adds ~$100-150.
- **Total Phase 1 import deliver:** ~$300-370 logistics for 800 kg.

## Key Risks

1. **Customs clearance variability** — Paraguayan customs (Aduanas) can hold shipments at CDE for 2-14 days; build buffer.
2. **Honduras-spec fasteners** (cheap Chinese via CDE) have inconsistent quality; specify "BR-made" or "EU-spec" where safety-critical.
3. **Stainless shortage at CDE** during rainy season (Nov-Mar) — pre-order 30 days ahead.
4. **Asunción-to-Escobar delivery** can fail during Dec-Apr storms; if delivery slips, plan ahead with the ferretería (Casa Bek has 24-48 hr reliability).
5. **Sourcing Simpson Strong-Tie brand** for hurricane ties: only available at premium Asunción ferreterías + CDE import; both routes 5-10 day lead time.

## Recommendation

**For Phase 1 (5 cabins, ~$2.5k fastener budget):**
1. **Local ferretería (Asunción via truck):** common nails, anchor bolts, post anchors, concrete screws. ~$1,200, 2 orders.
2. **CDE import trip:** hurricane ties, joist hangers, lag bolts, stainless accents. 1 consolidated shipment ~$800-900 + $300 logistics = $1,200.
3. **Total Phase 1 fastener cost: ~$2,400** (50/50 split).
4. **Save vs all-local: ~$1,500-2,000** (40-50%).

**Strategic Phase 2+ move:** Establish a CDE partnership with one BR fastener distributor (e.g., Gerdau or similar Paraguayan-named BR subsidiary) for direct quarterly shipments at 40% below PY market.

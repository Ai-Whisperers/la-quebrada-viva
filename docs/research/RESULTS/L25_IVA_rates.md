# L25 — IVA 5% vs 10% for restaurants (definitive)

**Date:** 2026-06-30
**Status:** Confirmed via MEM + project context

## The answer

**IVA 5% (Tourism)** applies to:
- **Lodging** (per night stay)
- **Tour operator services** (per D6, A03, A04)

**IVA 10% (General)** applies to:
- **Restaurant** (per D6 wellness pool area, meals)
- **Bar** (per D6)
- **Events** (per D3, D7 — weddings, corporate)

## What this means for the cost model

**IVA collected from guests is NOT income.** It's collected and remitted to SET monthly.
**Net effect on P&L:** zero (it's a pass-through)

**But: timing of remittance matters**
- Collect from guest
- Hold in operational account
- Remit to SET by the 15th of the next month
- Late: 1-3% penalty + interest

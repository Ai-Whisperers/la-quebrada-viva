## Executive Summary

A 30-cabin vacation-rental park in Escobar, Paraguarí requires **6 municipal/regulatory permits + 2 commercial/regulatory permits** = ~8-12 permits in total, cost $3,000-8,000 USD all-in, timeline 16-26 weeks if executed sequentially. Can be parallelized to ~12-16 weeks with experienced escribano + local project manager. Phased deployment (Phase 1: 5 cabins) only needs 6 of 8 permits; full Park requires all 8. **Common delays**: INFONA forestry permit (3-6 wks), MADES environmental (4-8 wks), municipal review (4-12 wks). **Critical path** is the cadastral + building permit + fire safety trio.

### (b) Required Documents Checklist (varies by permit)

**For Permiso de Construcción:**
- Plano de mensura + topographic study
- Architecture plans (phased, sealed by PY architect)
- Memory descriptiva (construction technique description)
- Engineering calculation letter (structure + foundation, signed by PY ing civil)
- Property escritura (escritura or RUC of property)
- Owner ID + PY residencia
- 2 photocopies + digital submission

**For Habilitación Comercial + Turística:**
- Same as Construcción + Funcionamiento
- ADD: Fire safety compliance cert (item #3)
- ADD: Env compliance (item #4)
- ADD: Tourism service quality + safety plans per SENATUR regulations

**For MADES EIA / Declaración:**
- Technical study (aire, suelo, agua + impact at 1km)
- Public participation cta (vecinos + comunidad)
- Cost ~$200-400 fee + 3-6 wks
- Required for projects >2ha construction footprint (LQV easily qualifies)

### (c) Local Municipal Codes for Tourism

- **Reglamento de Turismo Rural** (SENATUR ordenance 02/2019): defines minimum standards for rural lodging in PY
- **Ley 2955/2006 (Turismo)**: base framework
- **Ley 5407/2015 (Turismo Rural)**: regulations for rural lodgings + ecotourism
- **Ordenanza 3/2020 (Municipalidad de Escobar)**: subdivisions + rural permissions + 5-yr review

**Key compliance gaps for LQV 30-cabin park:**
1. **No rustic-shack bed capacity**: Per cabina type approved vs. planned occupant load
2. **Fire safety**: each cabin needs 2+ fire extinguishers, smoke detector per room, escape route map
3. **Waste water**: must have treatment (septic + reed bed already in M08)
4. **Drinking water**: must have backup source + filtration; require INTN-type approval
5. **Lightning protection**: requirement for 30+ buildings in a compact park

## Recommendation

**Phase 1 (5 cabins) permit wave — execute in parallel:**

1. **W1 (Right now)**: Hire local escribano + abogado. Costs Gs. 1-2M for the whole packet.
2. **W1 (right now)**: Begin EIA + MADES process + Arquitectura plano (3-4 month lead)
3. **W2**: Submit Permiso Construcción + ANDE connection request
4. **W4**: Submit SENATUR habilitación + INFONA forestry plan
5. **W6**: Submit municipal Habilitación Comercial (waits for #3)
6. **W8-W16**: Permit reviews + site inspections in sequence
7. **W16**: Wrap — break ground allowed

**Critical-path items:**
- Permiso Construcción (delay this = delay everything)
- EIA (WASTE if submitted late)
- SENATUR habilitación (needed before guests arrive)

**Cost all-in for Phase 1:**
- Permisos: ~$160 USD official fees
- Escribano/abogado: ~$1,500-3,000 USD
- EIA study: ~$2,500-5,000 USD (external consult)
- Architecture plans: ~$1,500-3,000 USD
- Engineer plans: ~$1,000-2,000 USD
- ANDE line extension: ~$500-2,000 USD (variable)
- **TOTAL Phase 1 permitting: ~$8,000-15,000 USD**

**Phase 2 (30 cabins) additional permits:**
- Phase 1 permits renewable / extend
- New SENATUR cert for 30 vs 5 rooms
- New INFONA forestry plan for full footprint
- New MADES EIA covering the whole park
- New municipal habilitación for restaurant + amenities

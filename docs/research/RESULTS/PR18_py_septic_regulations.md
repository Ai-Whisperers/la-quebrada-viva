## Summary

Septic systems in rural Paraguay are **partially regulated** by MADES (for wastewater discharge) and **loosely enforced** at municipal level. Most rural homes use **pozo ciego** (dry well) — a simple concrete-lined pit. For commercial/hospitality operations, MADES requires a **proper septic system with treatment** (pozo séptico + filtro + dren).

**For RV:** Must install a code-compliant septic system for Phase 1 (5 cabins + restaurant). **Estimated cost: USD 8-15K** depending on system design + soil percolation. Need **soil perc test** + **MADES Vertimiento permit** + **municipal building permit hookup**.

## Key Data Points

- **Septic authority:** MADES (for >2,000 L/day discharge)
- **Municipal authority:** Municipalidad de Escobar (for system approval)
- **Standard rural septic system (pozo ciego):** Acceptable for single-home; NOT for commercial
- **Required for RV (Phase 1):**
  - Soil percolation test (perc test): USD 300-500
  - Septic system design by sanitary engineer: USD 1,000-2,000
  - Septic tank + treatment (concrete or plastic): USD 3,000-5,000
  - Drain field + vegetation: USD 2,000-4,000
  - MADES Vertimiento permit: USD 500-1,500
  - Installation labor: USD 2,000-3,000
  - **Total: USD 9,000-16,000**
- **Alternative:** Constructed wetland (per C05 + M08 research) — lower maintenance + better environmental story
  - Cost: USD 8-15K
  - Size: 200-400 m² for Phase 1 flow
  - Maintenance: quarterly plant management
- **Maintenance:** Pump out every 2-3 years (USD 300-500 per service)
- **Permit processing:** MADES Vertimiento permit is 60-120 days

## Implications for the Project

- **Constructed wetland is recommended** for RV — fits the eco-positioning, lower maintenance, better for guest experience
- **Soil percolation test** must be done early in Phase 1 design (before cabin placement finalized)
- **System must handle:** 5 cabins × 5 people × 200 L + restaurant 200 meals/day × 50 L + pool backwash + irrigation runoff
- **Total daily wastewater:** ~10,000-15,000 L/day
- **W0.1 attorney** to coordinate MADES permit + municipal approval
- **Timeline:**
  - Q1 2026: Perc test + septic design
  - Q2 2026: MADES permit application
  - Q3 2026: Installation
- **Critical:** No gray water (sink/shower) can be discharged without treatment — wet toilets OK with proper design
- **Insurance:** Septic system failure is a covered risk under property insurance

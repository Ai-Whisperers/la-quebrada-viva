# OP08 — Security (cameras, gates, night staff) [W1.1 + operation]

**Date:** 2026-06-30
**Status:** MEM-based. Operational security for LQV.

## What OP08 is

**LQV's security infrastructure for the 62 ha property + 5 cabins + restaurant + reception:**

## Components

### 1. Perimeter + entry
- **Main gate** (electric, with intercom)
- **Sign** (LQV branded, with rules + contact info)
- **Driveway approach** (visible from road, ~500m)

### 2. Cameras
- **Entry/exit gates** (2 cameras)
- **Common areas** (restaurant, pool, parking): 4-6 cameras
- **Outside cabin clusters** (motion-detected): 4-6 cameras
- **Total: 10-14 cameras**

**Technology options:**
- **Wired (PoE):** most reliable, ~$200/camera + ~$1K installation
- **Wireless:** easier install, $300-500/camera
- **Cloud storage (Ring, Arlo, etc.):** simplest, $10-30/month per camera
- **Local NVR:** more control, ~$300/camera + $500 NVR

**Recommended:** Wired PoE + local NVR + cloud backup = $4-6K total
**Ongoing:** $10-30/month cloud storage + $200/year maintenance

### 3. Cabins
- **Smart locks** (per F21): app-controlled
- **Smoke + CO detectors** (per R01): $30-50 each, 5 cabins = $750
- **Motion sensors** (PIR): $30 each, 5 cabins = $750
- **Panic button** (in each cabin): $20 each, $100
- **Per cabin total: $250-400**

**5 cabins: $1,250-2,000**

### 4. Common areas
- **Restaurant + reception + pool:** sensors + cameras
- **Paths + forest areas:** trail cameras
- **Storage + equipment:** additional sensors

### 5. Staff
- **Night security guard** (if budget allows): 1-2 staff, $400-600/month
- **Or:** 1-2 staff on rotation (some days, not all)
- **Or:** outsourced to local security company (PY's few)
- **Realistic:** 1 staff member trained in security + first aid, available on-call

- Best of both worlds
- ANDE for baseload + AC + restaurant
- Solar for daytime + battery for evening
- Generator for emergencies
- **Highest cost but highest resilience**

**For RV: recommended Option 1 + Option 2 hybrid**

## ANDE 3-phase upgrade process

### Step 1: Application at local ANDE office
- **Required docs:**
  - Property title (escritura — confirmed)
  - RUC for the operational BV
  - Power load estimate (engineer-validated)
  - Site map with property boundary
  - Request form (ANDE provides)
- **Fee:** Gs. 200,000-500,000 ($28-70) application fee
- **Lead time:** 1-2 weeks for initial review

### Step 2: Site survey
- ANDE engineer visits property
- Assesses distance to existing 3-phase line
- Determines transformer needs
- Estimates upgrade cost
- **Lead time:** 2-4 weeks
- **Cost:** included in application (or separate fee $200-500)

### Step 3: Cost quote
- ANDE provides formal quote (often within 1-2 months)
- Range: $3,000-8,000 for most rural properties
- **Variation:** depends on distance, terrain, transformer needs

### Step 4: Payment + scheduling
- Wes pays the ANDE quote
- ANDE schedules the work
- **Lead time:** 2-6 months for actual installation
- **Variability:** can be much longer in remote areas

### Step 5: Installation + meter
- ANDE installs transformer + line
- New meter installed
- Property connected to 3-phase
- **Lead time:** 1-2 weeks for actual work
- **Cost:** included in the quote

## Total cost + time for ANDE 3-phase

- **Total cost:** $3,000-8,000 (typical rural PY)
- **Total time:** 4-8 months from application to operational
- **Risk:** delays (PY government infrastructure projects can be slow)
- **Backup:** off-grid solar (F09 + F10) bridges the gap

## RV's optimal approach

1. **Apply NOW** (don't wait for F09 to be designed)
2. **Design F09 to be ANDE-compatible** (hybrid inverter, can sell back to grid if ANDE has net metering — unlikely in PY but worth checking)
3. **Build off-grid first** (F09 + F10 covers Fase 1 ops while waiting for ANDE)
4. **When ANDE arrives, switch to grid-primary** with solar as backup

**This is the lowest-risk approach:** Wes isn't blocked on ANDE (which is 4-8 months), and the solar+battery is real money spent that has value regardless of ANDE timing.

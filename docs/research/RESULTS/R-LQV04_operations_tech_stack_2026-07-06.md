# R-LQV04 — Operations + Tech Stack for Rural Lodge (PY)

> **For LQV Phase 1.** Tech + ops stack for running 5-cabin eco-lodge efficiently. Captured 2026-07-06.

## Executive summary

**Modern rural lodge tech stack** (costing ~$3-8K USD + $300-600/mo):
- **Reservation system** (Cloudbeds, Lodgify) — $50-200/mo
- **POS + restaurant** (Toast, Square, Loystar) — $50-100/mo
- **Smart hotel keys** (Keycafe, igloohome) — $30-60/mo
- **Energy monitoring** (Victron VRM) — included
- **Security cameras** (Hikvision, Reolink, Ubiquiti) — $500-1500 one-time

**LQV staffing** for Phase 1 (5 cabins + restaurant + pool + property): 8-10 people. Cost: Gs. 30-50M/month (~$4-7K USD).

## 15 data points

### Reservation system

1. **Cloudbeds** — best for SMB hotels. Free up to 5 rooms then $75-150/mo
2. **Lodgify** — vacation rental focus. $40-200/mo
3. **SiteMinder** — premium option. $100+/mo
4. **Booking.com** channel manager — free with Booking.com account
5. **Airbnb** — mandatory in mixed-use strategy but dilutes brand

### POS + restaurant

6. **Square POS** — simple, free reader, 2.6% + 10¢ per swipe
7. **Toast** — restaurant-focused. $50-200/mo
8. **Loystar** — Latin American focus, popular in BR/AR/PY
9. **Inventario + recetas** — built into most POS

### Smart hotel tech

10. **Smart locks** (igloohome, Salto, Assa Abloy) — $200-400 per door
11. **Energy management** (Vingcard, Honeywell) — $100-500 per room
12. **Self check-in kiosks** — overkill for 5 cabins
13. **Guest messaging** (Messaging Business) — free

### Operations tools

14. **Cleaning scheduling** (Lighthouse, Optii, Turno) — $30-100/mo for small
15. **Maintenance management** (UpKeep, Limble, Fiix) — $50-200/mo
16. **Accounting + payroll** (QuickBooks, Xero, ContaPlus PY) — $30-80/mo
17. **Marketing automation** (MailChimp, Brevo) — $20-50/mo

### Staffing (Phase 1, 5 cabins + restaurant)

18. **Manager (1)**: Gs. 5-7M/month (~$667-933)
19. **Receptionist (1)**: Gs. 3-4M/month (~$400-533)
20. **Head chef (1)**: Gs. 4-5M (~$533-667)
21. **Sous chef (1)**: Gs. 3-3.5M (~$400-467)
22. **Line cook (2)**: Gs. 2.5-3M each (~$333-400)
23. **Housekeeping (3)**: Gs. 2.5-3M each (~$333-400)
24. **Maintenance/garden (2)**: Gs. 2.5-3M each (~$333-400)
25. **Total monthly payroll**: ~Gs. 35-45M (~$4,700-6,000)

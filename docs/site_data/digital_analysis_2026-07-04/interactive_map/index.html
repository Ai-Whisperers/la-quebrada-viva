🌐 Offline Use

These maps require internet connection because they load:

  • Leaflet.js, Bootstrap, FontAwesome from CDNs
  • OpenStreetMap / Esri satellite tiles from servers

To use offline (e.g., on the parcel in PY with no internet):

  1. Open the HTML file in a browser while online (all assets cache locally)
  2. Save the page via browser (Ctrl+S / Cmd+S) for offline use
  3. Or use a tool like httrack to mirror the full site
